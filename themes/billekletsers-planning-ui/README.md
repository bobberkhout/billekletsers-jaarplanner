# Billekletsers Planning UI 4.0.0

Lichtgewicht presentatiethema voor de plugin **Billekletsers Jaarplanner**.

Het thema bevat alleen:

- de rood-witte huisstijl;
- logo en basisopmaak;
- header en footer;
- een minimale frontpage die de Jaarplanner-plugin weergeeft.

Planningdata en beheerfunctionaliteit staan niet langer in het thema. Daardoor hoeft het thema bij normale functionele uitbreidingen niet meer te worden vervangen.

## Installatie

Activeer eerst de plugin **Billekletsers Jaarplanner** en activeer daarna dit thema. De bestaande gegevens worden niet geïmporteerd of gekopieerd; de plugin leest de al aanwezige WordPress-data rechtstreeks.
